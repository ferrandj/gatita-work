---
id: si-c1-ch4-l5
title: ORDER BY : trier
summary: Trier par ordre croissant (ASC, par défaut) ou décroissant (DESC), sur une ou plusieurs colonnes.
---

::: cours Trier le résultat
ref: 88 | Chap. 4 · II. E. Le tri | Il est possible d’ordonner les listes de réponses

**ORDER BY** trie les lignes du résultat :

- **ASC** : croissant (A→Z, petit→grand, ancien→récent). **C’est le tri par défaut**, ASC est donc facultatif ;
- **DESC** : décroissant. Il est **obligatoire** pour un tri décroissant.

```sql
SELECT attribut1, attribut2, attribut3
FROM table1
WHERE critère
ORDER BY attribut1 ASC, attribut2 DESC;
```

Avec plusieurs colonnes, le tri se fait **d’abord sur la première**, puis sur les suivantes (de gauche à droite). ORDER BY se place **à la fin** de la requête.
:::

::: sql si-c1-ch4-e20
ref: 99 | Chap. 4 · Application no 14 — V. B. | DESC est obligatoire puisque, par défaut, le tri est ASC
niveau: 1
base: ladore
ordonne: oui
== question
Liste des articles (**NumArticle, Libelle, PV_TTC**) classés **du plus cher au moins cher**.
== solution
SELECT Article.NumArticle, Article.Libelle, Article.PV_TTC
FROM Article
ORDER BY Article.PV_TTC DESC;
== explication
**DESC est obligatoire** puisque, par défaut, le tri est ASC (croissant).
:::

::: sql si-c1-ch4-e21
ref: 99 | Chap. 4 · Application no 14 — V. A. | Le tri s’effectue d’abord sur le nom, puis sur le prénom
niveau: 1
base: ladore
ordonne: oui
== question
Liste des clients (**Nom, Prenom**) par **ordre alphabétique** (nom puis prénom).
== solution
SELECT Client.Nom, Client.Prenom
FROM Client
ORDER BY Client.Nom, Client.Prenom ASC;
== explication
Le tri s’effectue d’abord sur le nom, puis sur le prénom (de la gauche vers la droite). ASC est facultatif.
:::

::: qcm si-c1-ch4-e22
ref: 99 | Chap. 4 · Application no 14 — V. C. | Une date est un nombre de jours depuis le 1er janvier 1900
niveau: 1
== question
Pour lister les clients **du plus ancien au plus récent** (Date_Creation), on écrit…
== choix
- [ ] ORDER BY Date_Creation DESC
- [x] ORDER BY Date_Creation ASC
- [ ] WHERE Date_Creation ASC
- [ ] GROUP BY Date_Creation
== explication
Une date est un nombre de jours : la plus ancienne a le plus petit nombre. Du plus ancien au plus récent = **croissant (ASC)**.
:::

::: ordre si-c1-ch4-e23
ref: 88 | Chap. 4 · II. E. Le tri | ORDER BY attribut1 ASC, attribut2 DESC
niveau: 1
== question
Remets dans l’ordre : les articles de plus de 1 000 €, du plus cher au moins cher.
== ordre
SELECT
Libelle, PV_TTC
FROM
Article
WHERE
PV_TTC > 1000
ORDER BY
PV_TTC DESC
;
== explication
ORDER BY vient **après** le WHERE, à la fin de la requête.
:::
